Fraud Detection in Online Transactions

Jan 2025
Python SQL Scikit-learn Logistic Regression Random Forest Gradient Boosting Streamlit
  • Built an end-to-end ML pipeline on 50,000 digital payment transactions (UPI, cards, net banking, wallets), reaching a 0.7085 ROC-AUC with logistic regression.
  • Ran exploratory analysis with SQL queries and extraction pipelines to surface patterns across merchant categories, authentication methods, and payment channels.
  • Engineered 10 behavioural and risk-based features — composite risk score, device-location risk flag, transaction velocity, amount deviation — from 25 raw attributes.
  • Found that a simultaneous device and location change multiplies fraud probability 6.2× (6.94% → 42.78%); threshold optimisation at 0.22 achieved 100% fraud recall and an estimated ₹6.27M net benefit.
  • Designed the 4-tier action framework above and deployed the scoring engine as an interactive Streamlit app.

Loan Approval Prediction

Jun 2026
Python Scikit-learn Gradient Boosting Random Forest Logistic Regression Feature Engineering Risk Segmentation
  • Built an end-to-end loan approval classifier on 14 demographic, financial, and credit features, achieving a ~0.975 AUC with Gradient Boosting — the best of three models compared.
  • Handled a heavily imbalanced dataset (~20% approved) using class-weight balancing; removed outliers including anomalous ages (max 144) and extreme income values before training.
  • Identified the five strongest approval predictors: previous default history, credit score, loan-to-income ratio, interest rate, and income — providing lenders actionable interpretability alongside accuracy.
  • Generated per-applicant approval probabilities and 4-tier risk segmentation (Low / Medium / High / Very High) on the full test set, exported to loan_predictions.csv.
